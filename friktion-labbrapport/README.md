# Labbrapport: friktion på lutande plan

En fristående skrivhandledning för Fysik 1. Öppna `index.html` direkt i en webbläsare; sidan kräver ingen installation eller byggprocess.

## Ändra handledningen

- **Instruktioner, formler och rapportmall:** redigera texten i `index.html`.
- **Färger, layout och utskrift:** redigera `style.css`.

Sidan kan skrivas ut eller sparas som PDF med knappen längst ned.

## Publicera på GitHub Pages

Om hela projektmappen publiceras från repositoryts rot ligger handledningen på:

`https://<användarnamn>.github.io/<repository>/friktion-labbrapport/`

I GitHub: öppna repositoryt, gå till **Settings → Pages**, välj **Deploy from a branch**, välj branch (vanligen `main`) och mappen **/(root)** och spara. GitHub publicerar `friktion-labbrapport/index.html` på adressen ovan.
