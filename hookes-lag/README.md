# Hookes lag – Fysik 1

En fristående webbsida utan paket eller byggsteg. Öppna `index.html` direkt i en webbläsare för att använda lektionen.

## Ändra lektionen

- **Undervisningstexter och standardtexter:** ändra värdena i `content.js`.
- **Fysik och tyngdacceleration:** ändra `gravity` eller beräkningarna i `physics.js`.
- **Utseende:** ändra `style.css`.
- **Sidans struktur:** ändra `index.html`.

Reglagen väljer massa och förlängning vid jämvikt. Fjäderkonstanten beräknas med `k = mg/x`. Animationen visar en idealiserad svängning utan dämpning.

## Publicera på GitHub Pages

Om hela projektmappen publiceras från repositoryts rot ligger den här lektionen på:

`https://<användarnamn>.github.io/<repository>/hookes-lag/`

I GitHub: öppna repositoryt, gå till **Settings → Pages**, välj **Deploy from a branch**, välj branch (vanligen `main`) och mappen **/(root)** och spara. GitHub publicerar `hookes-lag/index.html` på adressen ovan. Ingen GitHub Actions-konfiguration eller installation behövs.
